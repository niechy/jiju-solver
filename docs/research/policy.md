## 0. 结论摘要

**能击败。而且赢的不是"更多特征"，是"刷新决策规则"。**

当前冠军的候选择优是线性的（17 维权重），但**刷新决策是另一套东西**：三段硬门控 + 两道收益闸
（`features/jiji/world.go:475-488`）。我把刷新换成**用同一个线性价值函数做的一步最优停止**
（精确超几何期望 + 次序统计量，见 §2.3），其余一切不动（同样的 1-ply 四动作 rollout、同样 128 根采样、
同样的初值与协议）。留出集（两个从未用于任何训练/调参的种子）结果：

| 变体 | 留出种子 | n | Δ诗意 vs 冠军 | 2SE | t | Δ句数 | 相对提升 |
|---|---|---:|---:|---:|---:|---:|---|
| 停止规则（未调参，纯表示替换） | 202609401 | 400 | **+59.95** | 11.86 | +10.1 | +6.30 | 诗意 +12.6% / 句数 +14.5% |
| 停止规则（未调参） | 202609402 | 200 | **+49.83** | 16.52 | +6.0 | +5.28 | 诗意 +10.5% / 句数 +12.2% |
| **两个留出种子合并** | 401+402 | **600** | **+56.58** | **9.64** | **+11.7** | **+5.96** | 诗意 +11.9% / 句数 +13.7% |
| 停止规则 + 60 s 调参 | 202609401 | 300 | **+71.45** | 12.93 | +11.0 | +7.72 | 诗意 +15.0% / 句数 +17.8% |

同时我量化了**冠军自身的搜索余量**（§3）：根采样 128→512（算力 ×4）只值 **+8.0** 诗意，
续跑筛选样本 32→128（算力 ×4）只值 **+0.2** 诗意。
把冠军换成线上真实预算（`Samples=4096 / PolicySamples=128 / 1.5 s`）在训练集上**也没有变好**（§6.3）。

**反向结论（同样重要）**：
* "只加非线性特征、不动刷新规则" 没有收益——在**同一个停止规则下**开关非线性特征，配对差 **-7.54 ± 21.60（t=-0.70, n=120）**，即检测不到效应（§6.4）。
* 单独把刷新规则换成最优停止、**不套 rollout**，反而远不如冠军（-97 ~ -152 诗意）。冠军的力量主要来自
  "rollout + 续跑筛选"这套搜索结构，规则改进必须嵌进同一框架才生效。

## 1. 当前冠军是什么，怎么测的

### 1.1 线性启发式本体（判定的"被挑战者"）

* `features/jiji/strategy.go`：`Strategy` 共 17 个标量权重；`scoreCandidate` / `BaselineAction` 对候选做线性打分。
* 默认权重 = `EvolvedStrategy()`（`strategy_evolved.go`，`cmd/tools/jijievolve` 进化得到）：
  `NetGainWeight=31.84, RhymeBonus=234.84, XiangZhanBonus=4.36, RefreshPoetBonus=246.83,
  ShiyiWeight=5.09, OffRhymePenalty=50, SwitchThreshPct=0.1947, TargetPoolWeight=0.829,
  MinTargetPool=2, DryGroupFloor=9, LowLingxiFloor=5, RefreshGainFloor=0.8752, …`

**关键事实：刷新决策不是打分的一部分**（`world.go:BaselineAction`）：

1. 最优候选出韵 → 必刷；
2. 最优候选中间态且当前组 `cur > DryGroupFloor` → 必刷；
3. 当前组跌破 `SwitchThreshPct` 且下家最大组 `pool < MinTargetPool` → 必刷；
4. 付费刷的两道闸：`balance < LowLingxiFloor` 或 `p*8 < RefreshCost + RefreshGainFloor` → 撤销刷新，
   其中 `p = 1-(1-cur/len(st.left))^3`，`cur = st.groups[prev.Group1[0]]`。

这里有 4 个可测量的表示缺陷，全部是"线性模型无法表达"的量被粗近似替代：

* `cur` 只取**第一个**主韵组 —— 双韵/多韵句的真实押韵供给是**集合并集**；
* 分母 `len(st.left)` **包含本轮已展示（blocked）的句子** —— 刷新的真实抽样池比它小；
* 下家 `pool` 取"各组大小的**最大值**"而不是并集；
* `p` 是**有放回**近似 `1-(1-x)^3`，而实际是批内无放回（`DrawRound`）。

### 1.2 线上真正的决策器（`features/jiji/auto.go:57-79` + `live_objective.go`）

* `liveRolloutOptions()`：`MultiRollout`，目标 `shiyi-first`，`Samples=4096`、`MaxSamples=8192`、
  `Budget=1500ms/决策`、`PolicySamples=128`（先在一族状态相关策略里筛选续跑策略）、`ExactLimit=6`。
* 启动时另跑一次 60 s 的 `trainContinuationCached`（`liveTrainingOptions()`，目标 `shiyi-first`），
  独立验证通过则替换 `opt.Base`。
* 即：**冠军 = 线性启发式（可能被 60 s 进化精炼）当续跑策略 + 外层 4 动作 1-ply rollout + 续跑筛选。**

### 1.3 项目标准评测协议（`cmd/tools/jijiworld`，本研究沿用）

* 配对 episode：同一初始状态、同一 episode 种子 `sd = seed + ep*1000003`；策略 0 / 策略 1 各跑一整局；
  局内每个决策的规划器种子 `sd ^ (决策序号)*32452843`（worker 无关）。

  `n=200`、`seed=20260920x`、`samples=128`、`policy-samples=32`、`z=1`、`objective=shiyi-first`。
  注意：给了 snapshot 时命令行 `-cost/-lingxi` 被 snapshot 覆盖。

  （与旧报告一致）；`snapshot_sha256=ba061084d14da5973eabd1ecadb892c49209108bce8c2b6bf88ae160a03d0d88`。

### 2.2 复刻校验（保证比较公平）

| 校验 | 结果 |
|---|---|
| `modeLin` 续跑决策 vs `World.BaselineAction(DefaultStrategy())` | **0 / 67 决策不一致**（3 局全程逐决策比对） |
| `heur`（直接调 `BaselineAction`）vs `my:0`（我的复刻） | 诗意 / 句数 / 刷新数 / 决策数**逐位相同**（n=30，且与策略排列顺序无关） |

> 我的 rollout 框架与 `MultiRollout` 等价 ⇒ 后面所有差异来自**续跑策略/决策规则**，不是实现差异。

### 2.3 我尝试的 4 种续跑表示

| 模式 | 说明 |
|---|---|
| `modeLin` (=0) | 完全复刻 `BaselineAction`（线性打分 + 原门控级联）。**控制组**。 |
| `modeStop` (=1) | **候选打分完全不变**，只把刷新换成一步最优停止。 |
| `modeNL` (=2) | `modeStop` + 非线性特征 `p_hit / p_off / dens`。 |
| `modeLinNL` (=3) | 原门控级联 + 非线性特征（"只加特征、不动规则"的对照）。 |

**一步最优停止规则**：令 `S(·)` 为线性（或含非线性项的）打分，`R` 为**刷新后真正会从中抽句的池**
（未收集 ∩ 未在本轮展示 ∩ 非当前候选），`k = min(3,|R|)`：

```
刷新的期望价值  EV = E[ max_{batch ⊂ R, |batch| = k} S ]
                  = Σ_i S_(i) · C(i-1,k-1)/C(R,k)      （S_(i) 升序；精确次序统计量权）
付费刷新        EV -= RefreshCostWeight · RefreshCost
决策            刷  ⟺  EV - cost > S(best) + StopMargin
```

非线性特征（只在 `modeNL`/`modeLinNL` 生效）在**选中句 v 之后**的池上精确计算（**集合并集**）：

* `p_hit(v) = 1 - C(n-r,3)/C(n,3)`：下一批 3 句里至少一句与 `v` 押韵的概率（超几何，精确）；
* `p_off(v) = C(n-r-m,3)/C(n,3)`：下一批全部出韵的概率；
* `dens(v) = r/n`：剩余池中与 `v` 押韵的句占比。
  其中 `r`/`m` 用 `Group1`/`Group3` 的交集在剩余池上精确计数（冠军用的是 `Group1[0]` 与组最大值）。

### 2.4 60 秒时间盒的权重搜索

只搜 5 个**非线性/规则**参数（`StopMargin`、`HitProbWeight`、`OffProbPenalty`、`DensityWeight`、`RefreshCostWeight`），
线性核心 17 个权重**固定为冠军值**，使"表示改变"与"重新调参"可分离。
搜索 = (1+λ=8) 多尺度（{0.02,0.05,0.15,0.40}）爬山，配对同种子评估，接受阈值 `Δ > 1.5·SE`，
预算 60 s（与 `liveTrainingOptions()` 一致），训练数据 = seed 202609202 的 64 局，目标 = 直接使用该续跑策略的平均诗意。

| 搜索 | 60 s 内 | 训练目标（直接策略均值） | 结果 |
|---|---|---|---|
| `-tune-mode 1`（停止规则） | 953 代 / 8578 次评估 | 306.7 → **376.1** | `StopMargin=-100`、`RefreshCostWeight=49.2`（另 3 个非线性权重在 mode 1 下**不生效**） |
| `-tune-mode 2`（停止规则 + 非线性特征） | 863 代 / 7768 次评估 | 306.7 → **393.9** | `StopMargin=-100`、`RefreshCostWeight=13.1`、`HitProbWeight=285.4`、`OffProbPenalty=-300`、`DensityWeight=30.9` |

> 注意：mode 1 下非线性特征本来就不参与打分，所以上表第一行的三个非线性权重是**惰性噪声**；
> 这解释了 §6.4 里 T5a 与 T5b 完全相同。

## 7. 判定：线性启发式是否已到该表示的极限？

分两层：

1. **决策规则层：远未到极限——这是本次的主要发现。**
   同一个线性价值函数，只把刷新从"三段硬门控 + 两道收益闸"换成"一步最优停止"
   （线性权重一个都没动），留出集合并 n=600 上拿到 **+56.58 ± 9.64 诗意 / +5.96 句数**（t=11.7），
   60 s 调参后 n=300 上 **+71.45 ± 12.93**（t=11.0）。
   机制清楚：冠军对"刷新的边际价值"只有 4 个粗糙判断位（`cur` 取首个主韵组、分母含已展示句、
   下家池取组最大值、命中率用有放回近似），而最优停止直接用精确超几何期望与次序统计量权衡
   "接受眼前最好"与"再抽一批的期望最好"。

2. **价值函数层：线性打分没有被证明是瓶颈，但也没有被证明够用。**
   * 冠军自身的搜索旋钮（根采样 ×4、筛选样本 ×4、线上 4096 档）余量 ≤ +8 诗意；
   * 在正确模式下（mode 2）加非线性概率特征，60 s 调参后与同等停止规则相比 **-7.54 ± 21.60（检测不到增益）**；
   * 唯一没做的方向是"用 CMA-ES / 梯度在 17 维线性权重 + 非线性项上**联合**搜索"，
     或"直接学一个后状态价值函数"。本次只搜了 5 个规则/特征参数，线性核心固定为冠军值，
     所以**不能**宣称线性表示已到顶，只能宣称：**在当前可达的搜索预算下，决定性的瓶颈是决策规则而不是特征。**
   * 一个可检验的进一步假设：把停止规则的"价值"从启发式打分换成一个学出来的 `V(state)`，
     可能才是突破线性表示上限的路径；这需要远大于 60 s 的训练预算。

**落地建议（约 40 行改动，不需要重训权重、不需要额外预算）**：
把 `features/jiji/world.go:BaselineAction` 的刷新门控级联替换为
`EV = Σ_i S_(i)·C(i-1,k-1)/C(R,k)`（`R` = 未收集 ∩ 未展示 ∩ 非当前候选）形式的
一步最优停止，`S` 沿用现有线性打分；`StopMargin` 初始取 0，`RefreshCostWeight` 取 `NetGainWeight`。
（`StopMargin=-100`、`RefreshCostWeight≈13–49` 是我在单快照上的搜索结果，跨池普适性未验证。）
